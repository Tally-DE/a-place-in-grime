# Help document a grime artist

A remembered stage name is enough to start. If you recognise an old alias, have a tape inlay or know where a profile has got a town wrong, you can help.

## Suggest an artist

Open **Suggest an artist** on the homepage or a place page. Enter the name as you remember it. A city or town, crew, rough year or source can help the editor distinguish between people who used the same name. The other fields are optional.

## Check or correct a fact

Open the artist’s profile and find the statement and its source. Use **Verify this source** to report what you found. Choose whether the source supports the statement, partly supports it, contradicts it or is unavailable. Give the editor the paragraph, page, timecode or physical collection you checked.

For a change to a statement, use **Suggest a correction** beside it. Describe the change and how you know. The form carries the artist, claim and version you saw. Use **Contact the editor privately** on the Contribute page for sensitive corrections or removal requests.

These website forms accept guest submissions. A public credit name is optional. Bookmark the private receipt after sending. The editor reviews a contribution before updating any public record. Keep private contact details, sensitive testimony and material without permission out of GitHub.

## Give your agent a task

On **Agent research**, choose a place and either one task or an amount of time. Open the brief and give the link or its text to your own agent. For example, “Follow this brief and work on Derby for 30 minutes.” A timed run can work through several ordinary tasks. The agent handles sources, checkpoints and handoff. [Public brief to give an agent](https://raw.githubusercontent.com/Tally-DE/a-place-in-grime/main/research/AGENT-LINK.md)

For a first session, use the provider setup links on the Agent research page, then sign in to your own account. Choose a session that can open websites and save files. If you want it to reserve a public question and submit directly, sign in to your own GitHub account when prompted. Check your provider’s current plan, price and usage limits before purchasing a subscription. You can suggest artists, correct facts and verify sources directly on the site without an agent.

The agent reserves a single question from the public queue. It follows the research rules, identifies who each source connects to, and returns an evidence packet and a receipt. If it can work with GitHub, its packet goes to a pull request. If a read-only assistant produced a packet, use **Send a completed packet privately** on the Agent research page. Save the receipt once the site confirms delivery. [Available tasks](https://github.com/Tally-DE/a-place-in-grime/issues?q=is%3Aissue+is%3Aopen+label%3Aresearch-task) · [Research and archive rules](research/METHOD.md) · [Submission and review](research/REVIEW.md)

## What the editor checks

The contributor gathers evidence and follows leads. The maintainer-side reviewer checks each proposed fact at its cited location, keeps unclear identities open and publishes supported changes to the accepted catalogue. A source check, an original discovery and a correction can all be credited. Website receipts are private. A public GitHub submission has a public review thread. [Catalogue records](catalogue.json)

## Try the real Derby exercise

Open the checkout in your agent and ask it to follow the Derby practice task. The practice route shows how a peer recommendation leads to a second source and a previously unrecorded production credit. The exercise earns no public credit.
