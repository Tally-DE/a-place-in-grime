## Add a collection

Anyone can suggest a channel, radio archive, label catalogue, blog, flyer collection or run of tapes. You can send a source-only pull request without opening an artist task. On a public artist assignment, include the directory edit in the same pull request. For private delivery, put the proposed addition in the packet's `trail_note` so the editor can add it after checking. A source without a live URL can have a public collection or shelf reference. Keep private collectors' details off GitHub.

1. Search this directory for the name, old names and a stable ID. A YouTube channel ID is more durable than a handle. If the collection already has an entry, extend it there. Link other places to the same entry when it covers several scenes.
2. In the place file give the collection's name, aliases, link or reference, and what a researcher can find there. For a new place, add a Markdown file here and link it in the table above. Record the sample item or publisher's account that identifies the collection. If the identification is still open, label the lead and say what would settle it.
3. Under **Checked**, append a date, the exact item, playlist section or range examined, and what you could see or hear. Use stable video IDs, original URLs or references. If a replay survives, keep its capture URL as well. Mark a mirror as a copy of its original. A search result or a channel landing page alone leaves the contents unchecked.
4. Under **Pick up here**, leave a particular credit, item, date range or shelf to check. Consult the open research queue before taking it. The place file records coverage. The issue reserves a question. Other people can work elsewhere in the same collection.

The location in this directory describes the collection's relevance. Verify each artist's city, role and grime connection from the actual material before proposing a profile. An archive upload can postdate a performance by years. Reuse of an image needs the rights holder's terms for that item.
